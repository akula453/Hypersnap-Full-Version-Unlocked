- **Full-Screen Capture** — Capture the entire screen with one click, helpful for presentations or tutorials.
- **Active Window Capture** — Instantly capture the currently active window, making it easy to share specific content.
- **Region Capture** — Select a rectangular or freehand area to capture only the necessary parts of your screen.
